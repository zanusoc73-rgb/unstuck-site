An external hard drive won't show up, even though it spins up

Applies to Windows and macOS, USB and USB-C external drives.

If the drive spins up (you can hear or feel it) but doesn't appear in File Explorer or Finder, the physical connection is working but the computer isn't recognizing the drive's file system — a data problem, not a power problem. That distinction changes which fix actually applies.

Work through it in this order

  1. Check Disk Management (Windows) or Disk Utility (Mac) before anything else. These tools show drives at a lower level than File Explorer or Finder. If the drive appears there but greyed out or "Unallocated," the drive is detected but not mounted — a very different (and more fixable) situation than the drive not appearing at all.
  2. Try a different USB port and a different cable. Ports on the back of a desktop or on a hub often supply less power than a drive needs to spin up and communicate reliably. Plug directly into a port on the computer itself, not a hub or dock, and swap the cable if you have a spare.
  3. Assign a drive letter manually (Windows). In Disk Management, right-click the drive and choose "Change Drive Letter and Paths." Sometimes a drive mounts successfully but without a letter assigned, so it simply never appears in File Explorer.
  4. Test the drive on a second computer. This is the fastest way to tell whether the problem is the drive itself or your specific computer's ports/drivers. If it doesn't show up anywhere on a second machine either, the drive itself has likely failed.
  5. If the drive shows as "Unallocated" or asks to be formatted, stop before clicking format. This usually means file system corruption, not necessarily lost data. Formatting will erase everything permanently. If the data matters, use read-only recovery software (or a data recovery service) before formatting anything.
most common fix

Plugging directly into a rear or built-in USB port instead of a hub or the front panel of a desktop (step 2) resolves the majority of "spins up but invisible" cases — external drives are more power-sensitive than most peripherals.
